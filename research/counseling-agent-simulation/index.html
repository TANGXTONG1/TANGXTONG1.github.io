ECAs：心理学理论驱动的来访者智能体仿真

ECAs 以心理学理论组织模拟来访者的人物画像和具身认知记忆，生成可评估的咨询对话，并提供公开数据与代码，支持对话智能体研究。

唐苑容 · 共同第一作者（署名第二位）

研究问题

如何让合成咨询对话反映来访者的经历、信念和心理过程，而不只模仿语言表面？

方法与研究范围

依据心理学理论，从 D4 数据扩展人物画像与具身认知记忆，检索相关记忆生成对话，并结合咨询师和自动评估。

阅读这篇论文可以了解什么

提供理论驱动的模拟来访者建模方法；具身主要指认知与记忆，而非身体动作仿真。

结果的适用边界

研究评估特定数据和情境下的合成对话质量，不能据此认为完全复现真实人的行为，或已验证临床效果。

Research in brief

ECAs builds theory-grounded simulated counseling clients by expanding case data into profiles and embodied cognitive memories. Context-sensitive memory retrieval supports dialogue generation, which is evaluated by counseling professionals and automated methods. The project provides public code and data for further research.
