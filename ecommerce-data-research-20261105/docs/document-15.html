国内电商数据平台浏览器试用核验

核验日期：2026-11-05。本轮已对 34 组尝试浏览器访问/试用，其中 31 组得到清楚的访问结果，3 组因页面或自动化读取异常未完成；另外 15 组未完成浏览器测试，以文档核验为主，其中好单库另取得一次公开 HTTP 数据响应。清楚的访问结果包括登录、注册、商务留资、移动端或凭证要求，不代表数据接入成功。

实际取得 2 组公开网页数据预览、0 次鉴权业务 API 成功、0 个供应商 Excel/CSV 导出文件、0 次注册；另已保存 1 份好单库公开活动 JSON 响应。没有提交申请/留资表单或完成付费。达多多公开预览含遮蔽/区间字段，导出点击后要求登录；商指针公开预览日期为 2025 年 1 月，不能当作当前数据。

后续浏览器工具状态异常：可访问性树（AX）和截图均无法正常取得，剩余测试中断，没有完成 49 组浏览器测试。艺恩仅尝试导航并读到标题，未形成可核实页面结果，仍列为未完成。灰豚、电霸、DataEye 的异常也不能直接等同于供应商不可用。

好单库补充检查：官网公开活动地址无需 Key、登录或 Cookie，实际返回 HTTP 200、3 条商品及 41 个商品字段；这不是浏览器试用，也不是鉴权开放 API 或真实订单验证。原始 JSON、验证记录、质量说明已保存。样本存在优惠券总量与已领/剩余量矛盾，以及结构化价格与条件优惠文案价格不同，不能当作精确比价或销量核算基准。
