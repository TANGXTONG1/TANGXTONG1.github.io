核验日期：2026-11-13。此轮接续前一天的供应商筛选，逐家访问官网、读取具体输入参数与返回字段，并尝试官方提供的公开演示及业务端点。统一入口见研究站的“海外接口测试总表”。

Magpie、SellerApp、Unwrangle、Zyte、Decodo 按正式接口无凭据请求 HTTP 401 仍需合法试用凭据；不算采集失败
Apify 五站 Actor 正式运行端点，不带 token HTTP 402，要求 token 或付款凭证 必须以自己的试用账号继续；没有启动采集任务
Scrapingdog、ScraperAPI 专用接口 按官方文档构造无密钥/字面占位符请求 出现 401、403 或无密钥 404 等认证响应 不能将认证前的 404、接口文档 HTTP 200 或营销成功率当作业务验证

BlueCart 和 Countdown 的 demo 是供应商公开提供的演示模式；本文没有把它们计为生产账户成功采集。公开演示不一定代表实时数据，示例日期、默认商品和可改参数需要在认证测试中另验。

公开的 演示短摘录与字段样本 中，BlueCart 前两条日期在 2020 年，Countdown 前两条在 2022/2023 年。它们可以用于理解字段格式，不能据此承诺当前最新评论或增量更新能力。

两家的账户创建尚未提交，服务条款授权仍待确认。没有创建这两家的密钥，也没有领取到账户或运行账户内的免费任务。此前国内供应商账户不代表这些海外供应商已经注册。

电脑操作曾成功读取 Chrome 页面并运行 Scrapingdog 匿名演示，之后继续读取遇到 noWindowsAvailable 和 codex app-server exited before returning a response。这属于本地工具故障，不作为供应商失效证据。

官网与参数的实质差异

  • Bright Data 的 Best Buy Reviews 宣传页代码示例使用商品采集器 gd_ltre1jqe1jfr7cccf；独立评论采集器应按当前机器目录核对 gd_mv3s5qosodai3txro。不能照抄营销页后把商品结果当作评论分页。
  • Apify 的 Shopee 候选通过店铺评价流匹配商品，schema 中有每星、每店铺的数量边界；商品可能只匹配到店铺流中的部分评论。参数允许取很多条不等于保证完整历史。
  • 统一账号或统一请求外壳，不等于各站字段、评论类型、分页、计费单位完全相同。网页逐行保留端点、认证方式、必填参数、输出字段、地区、限制与来源。

怎样阅读网页上的状态

“官网可访问”是站点访问结果；“文档/样例已读取”说明可以检查格式；“认证门槛”说明还未进入真实取数；“公开演示已返回”说明供应商允许的 demo 路径有响应；只有使用自身合法凭证、记录业务返回与扣费的请求，才列为“认证业务实测”。这些状态不能混算成功率。

无密钥请求的耗时只是认证层响应时间。无数据的请求正文条数记为“未取得/未知”，而非假设商品有零条评论。每千请求、每千商品页和每千评论的报价也分别保留，不使用统一价格排名掩盖单位差异。
