本轮最值得进入接口选型的组合

  1. 跨货架电商市场数据：先魔镜；任拓作为评价/促销强候选，先确认交付。 魔镜公开接口证据强，但拼多多/美团在旧文档枚举中出现并不能保证当前全字段可用；必须按平台拿当月样例。
  2. 内容电商：蝉妈妈（API明确） + 新榜（定制API明确）；需要小红书精细营销分析可加千瓜导出。飞瓜功能强，但 API 尚不能写已确认。
  3. 跨平台消费者声音：魔镜电商聆听、任拓倾听、数说故事。 要特别询问原文、评分、时间、商品ID/SKU、追评、商家回复等逐条字段，以及是否提供 API/CSV。只交情感得分/标签/趋势图无法替代原文库。
  4. 本地生活竞品：魔镜/任拓/久谦做供应商样例询证，窄门餐眼补门店/商圈。 本轮没有证据证明任一分析SaaS能同时完整输出美团全量精确销量、原文评价、价格与竞争对手真实广告消耗。
  5. 流量/营销补充：QuestMobile 有明确标准API/批量交付。 不把它放进 SKU 订单层。

魔镜接口复核要点（给主报告使用）

  • 文档明确区分 MMI 市场情报与价控；MMI 的 SiteTrend / SiteHotItems / SiteCompare 等参数列出 pdd、meituan，但 CategoryTree / LatestMonth 的平台枚举较短。ShopSale / ItemSale 明确仅列淘系及京东相关平台，未列 pdd/meituan；ShopDetail 只列淘宝+天猫、京东、国美、苏宁。不能一概视为所有接口支持所有平台。
  • SiteHotItems 是类目/品牌下热销商品行，包含商品 ID、标题、店铺、销量、价格等，并不是平台原始订单明细；还有多个价格模型字段，商品行也不能自动叫 SKU 交易账本。
  • ItemPriceTrend 是商品+SKU价格趋势，公开 plat 只列 taobao/jd。
  • SiteCommentTrend 返回评论数量及好/中/差评率时间序列；它不是评论原文接口，文档还注明淘宝/淘宝+天猫无此数据。
  • 文档示例含 2015–2021 等旧时间；页面今日可读只证明文档存在。当前可售渠道、最近更新时间、历史回补、单接口字段、价控采样频率与评论原文交付，应通过 APIKEY 权限和样例验收。
