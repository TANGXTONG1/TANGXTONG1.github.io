海外电商接口测试说明

核验日期：2026-11-13。本轮已从官网、公开演示和无凭据检查，推进到授权账户内的真实采集。统一入口见研究站的“海外接口测试总表”。本说明以 认证实测记录 和此前各供应商的测试文件为依据；不同验证层级分别呈现，不混算成功率。

已认证业务实测

截至当前，Apify 已通过授权账户完成 Amazon、Walmart 各 5 条评论的小样本采集；Bright Data 的 Walmart 返回 4 条非空评论，Best Buy 返回 20 条，Lazada 返回 2 条，Amazon 则返回拦截错误。Best Buy 的最近 1 天筛选在本样本中未生效，不能把这次返回视为最新评论或可靠增量采集的验证。Lazada 单次采集耗时约 14 分 38 秒，接入应支持异步轮询。

Bright Data Walmart 的首次认证请求返回 bad_input：days_back 需要同时指定 sort_by=Most recent。该次 HTTP 往返 23.996 秒，属于参数校验响应，不纳入采集成功率；补齐参数后的成功响应单独记录。两次请求均不能只凭 HTTP 200 判断业务结果。

Best Buy 的首次请求恰好不同：sort_by=Most recent 被 HTTP 400 拒绝，耗时 1.667 秒；移除该参数、保留 days_back=1 后才返回 20 条正文。两次参数行为说明排序值不能跨采集器直接复用。成功响应中的评论距测试日期已一年以上，日期筛选本样本不生效，增量可用性没有通过验证；不能把取到正文等同于取到最近一天的评论。其输出虽有 review_page_number，本轮没有验证可用的翻页参数或游标。

Apify 两次合计扣试用余额 $0.055，没有付费充值。这是两个小样本任务的实际费用，不能直接外推大规模单价或长期成功率。Amazon 返回日期覆盖 2025-12-12 至 2026-10-16；Walmart 返回日期覆盖 2026-10-06 至 2026-11-01。日期表明输出包含这些时间的评论，不证明所有历史评论、最新评论排序或增量更新均完整。

Apify Amazon 样本包含正文、标题、评分、日期、商品 ASIN、变体、验证购买状态等字段，另有 reviewImages 字段；Walmart 样本包含正文、标题、评分、提交时间、商品 ID、反馈数和 photos 字段。字段存在不等于本次每条都有图片。商家回复及完整历史分页尚未验证。Walmart 输出带 syndicationSource / externalSource，后续应核对转载评论来源与商品匹配。

Bright Data Walmart 成功响应含 review_text、review_header、rating、review_posted_date、review_id、product_id、is_verified、helpful_count、not_helpful_count、review_page_number、videos、item_details 等字段；视频字段存在不代表每条有视频。4 条非空正文证明本次目标与参数组合取得了评论，不证明完整历史、完整媒体或商家回复能力。

Bright Data 的 Amazon 请求与 Apify 的 Amazon 测试针对同一商品作对照。本次 ready 只说明快照已可下载，HTTP 200 只说明导出成功；下载内容是一条错误记录，不能算一条评论，也不能据此断言该商品没有评论。此前另一次控制台点击没有保留可核验结果，不作为第二次已完成业务运行计数。

账户、授权与浏览器状态

截至本轮，相关注册、登录及服务条款步骤已获得用户授权并完成：Apify 使用已登录的现有 Free 账户，额度为 $5；Bright Data 已注册 Free tier，运行前观察到 5,000 免费 credits，未添加信用卡或付款方式。两家均未充值。密钥与完整账户信息不公开。

用户最新约束是：UI 操作仅通过浏览器标签页插件，不允许桌面操作。 用户已确认桌面客户端显示 Edge 已连接；插件能够列出和新建标签页，但读取页面和导航仍超时。连接显示与实际标签页控制尚未一致；这属于本地工具故障，不是供应商错误，也不改变上表已经保留的 API 实测结果。

此前曾遇到的 noWindowsAvailable、codex app-server exited before returning a response 同样归为工具故障。本文不会把旧的工具故障或当前插件超时计入供应商成功率。

参数与结果仍需注意的差异

  • Bright Data 的 Best Buy Reviews 宣传页代码示例使用商品采集器 gd_ltre1jqe1jfr7cccf；独立评论采集器应按当前机器目录核对 gd_mv3s5qosodai3txro。商品结果不能当作评论分页证据。
  • Apify 的 Shopee 候选通过店铺评价流匹配商品，schema 中有每星、每店铺的数量边界；商品可能只匹配到店铺流中的部分评论。允许设置较大数量不等于保证完整历史。
  • 统一账号或统一请求外壳，不等于各站字段、评论类型、分页、地区限制、权限和计费单位完全相同。两站小样本成功也不能推出同一供应商所有平台均成功。

状态与时间如何比较

“官网可访问”“文档已读取”“无凭据认证响应”“公开 demo 返回”和“认证业务实测”是不同证据层级。认证业务实测还要区分触发是否成功、任务是否完成、导出是否成功、是否拿到非空评论正文，以及是否实际扣费。任务成功或 HTTP 200 单独出现，都不足以证明取得了目标评论。

无密钥请求耗时只是认证层响应时间。Apify 控制台运行时间、Bright Data 触发请求时间与采集时长分别保留，不放在同一速度排名中。没有取得评论时，记录“本次 0 条正文”或“未知”，不能据此判断商品本身没有评论。每千请求、每千商品页、每千评论的标价与实际任务扣费也分别保留。
