# 样本下载说明

本目录严格区分以下三类证据。所有内容核验日期为 2026-11-05；观察日期与数据日期可能不同。

| 证据类型 | 本次文件及内容 | 能证明什么 | 不能证明什么 |
|---|---|---|---|
| 真实 HTTP 响应 | `好单库-公开活动商品响应-2026-11-05.json`：实际匿名 GET 返回，3 件商品、41 个商品字段 | 该公开地址在本次请求时确实返回这些字段和值 | 鉴权开放 API 可用、平台真实订单、销量准确、全库覆盖 |
| 浏览器 UI 观察 | `ui-observed-excerpts.json`：达多多 1 个商品、商指针 2 个行业的人工转录 | 本次会话实际 getAXState 可访问文本中出现这些展示值 | 供应商导出文件、API 返回、平台原始订单 |
| 文档示例 | 本目录没有把供应商文档示例作为实际数据文件 | 文档可用于识别格式或字段 | 文档示例不能算本次实调成功 |

UI 观察数据从本次会话 UI 可访问文本人工整理，非供应商导出/非 API 返回。

达多多样例保留原展示口径：30 日销量、直播销量、商品卡销量为 `10w+`，视频销量为 `2w~10w`；它们不是精确订单量。转化率保留 `20%~25 %`，关联达人 `1,535`、关联直播 `2,451`。价格显示被遮蔽，未还原；佣金未转录，字段省略。点击导出要求登录，没有获得文件。

商指针样例数据期为 **2025-01**，观察日期为 **2026-11-05**。公开页可见 20 个行业，文件仅转录会话留存的“手机及配件”和“服饰”2 行。行业份额与增速是页面展示值，未追溯分母或订单底表；不能当作当前行业数据。

好单库原始响应存在两项已记录的质量问题：券总量与已领/剩余量不一致；结构化券后价与营销文案的叠加优惠到手价不同。详见 `好单库-公开活动响应样本说明.md`。原始 JSON 未修改。

当前仍为 **0 次鉴权业务 API 成功、0 个供应商 Excel/CSV 导出、0 次注册**。好单库浏览器 UI 未测，但已实际取得公开 HTTP JSON。研究生成的验证记录、说明和 UI 人工转录均不能计作供应商数据导出。

`index.json` 提供文件相对下载 URL、字节数及 SHA256。网站 `data/samples.json` 提供结构化预览；完整原文件在此目录保留。
